Definition of done for runs

A run cannot end until its dod holds.

An operator types a prompt. Before the agent's first tool call, the wrapper loads a definition of done that a person authored, or asks Oxagen to draft one, and locks it into the run's chain. The agent can read it and cannot change it. When the run tries to stop, the checks run on the agent's own host. Broken, and the agent gets the failing ids and keeps working. Held, and Oxagen settles it as a server-attested frame the seal signs, which anyone with the export can recompute offline. The dod is the visible half of proof. Witnesses, the hidden half, stay exactly as Mission Control already defines them.

See a dod file
1. turn_startLoad an authored dod from .oxagen/dod/ by task reference, or draft one. Lock it. Emit dod.locked before any tool frame.
2. stopRun every executable check here. Emit one dod.checked frame with every result. Fold the chain. decide().
3. block or reportBroken with attempts left: block the stop with the failing ids. Otherwise report the stop through the checkpoint gate.
4. settleOxagen reads the chain, runs the same decide(), appends dod.settled, records one governed action. The seal signs it.
5. verifyAnyone with the run export runs oxagen dod verify. Same function, same frames, same bytes. No account, no network.

What was cut, and why

Four kinds, two hooks, two capabilities, no table

The 14 September review makes one argument about the whole product: the surface is fine, the ordering is not, and anything that duplicates a thing the platform already does should go. Read against that, the previous draft of this spec still carried five things Mission Control already owns.

One thing was added. The review names verify as the most valuable idea in the earlier spec, because it makes an outside party a user of Oxagen's records. It is back as fifteen lines that run against the run export Mission Control already produces, with no network and no account.

Fit with Mission Control

The dod is the visible half. The witness is the hidden half.

Mission Control §8.5 already defines a witness: a check Oxagen writes, runs in an isolated runner the worker never sees, and measures as a flip against the PR's target. Only flipped makes a run proven. The dod does not touch that. It answers a different question, for a different reader, at a different point in the run.

Same vocabulary

Run, turn, step, frame, operator, agent, workspace, main repo, governed action, enforcement tier. Not session, not trace, not attempt in anything a customer reads.

Same seams

Claude Code reaches the three points through the hooks the enrollment already writes. Every other adapter reaches them through the checkpoint gate. The dod adds no seam.

Same chain

Three frame kinds, no table. The lock is a frame, the checks are frames, the settlement is a frame Oxagen appends. The seal's Merkle root covers all of them.

Vera reads both halves. A held dod and a flipped witness on the same run are the tuple its ladder, rating, and improvement certificate consume. Nothing in this spec is Vera-specific; it produces the record Vera prices on.

The dod file

Four check kinds, in the format .oxagen already uses

Authored dods are TOML under .oxagen/dod/, published on the main repo's default branch like steering. A drafted dod has the same shape, is never written to git, and travels in the dod.locked frame. The wrapper writes a read-only copy to $OXAGEN_RUN_DIR/dod.toml so a person can read what the agent was held to.

# .oxagen/dod/keys-rate-limit.toml
# Authored by a person and published on the main repo's default branch, like every other .oxagen file.
# A drafted dod has the same shape, never touches git, and travels in the dod.locked frame.

task   = "Add per-key rate limiting to POST /v1/keys"
match  = { task_ref = "github:macanderson/oxagen#2701" }
stop_attempts = 3          # how many times the wrapper may block the stop before the run ends broken

[[check]]
id  = "unit"
run = "pnpm --filter @oxagen/api test:unit -- keys"

[[check]]
id  = "typecheck"
run = "pnpm --filter @oxagen/api typecheck"

[[check]]
id   = "scope"
diff = { allow = ["apps/api/**", "packages/rules/**"], deny = ["packages/database/migrations/**"] }

[[check]]
id   = "wired"

[[check]]

KindPasses whenEvidence in the frame
runThe command exits 0 inside the timeout, with credentials scrubbed from the environment.sha256 of stdout and stderr
fileThe path exists, contains the string, or matches the digest.sha256 of the file bytes
diffEvery changed or new file against the run's base commit matches an allow glob and no deny glob.sha256 of the diff manifest
humanA named person signs it after the run. It never blocks the agent; it holds the verdict at pending.the signature

No hidden checks, no tool rules, no budgets. Witnesses, the toolbelt, and Mission Control budgets own those. stop_attempts is the one limit the dod carries, because it is the one nothing else defines.

Frames

Three frame kinds, one chain, no table

Everything the dod knows lives in the run's hash chain. That makes every dod question a chain question: locked in time means the dod.locked seq precedes the first tool frame; unchanged means every dod.checked carries the same lock digest; settled means Oxagen appended the frame and the seal covers it.

KindEmitted byLedger stageBody
dod.lockedwrapper, at turn_startcontextthe whole dod, its lock digest, task reference. Client-attested, Oxagen-countersigned.
dod.checkedwrapper, once per stopverificationstop attempt, lock digest, and every result: id, ok, evidence digest, error flag
dod.settledOxagen, on stop reportverificationverdict, reasons, failed ids, stop attempts, enforcement word. Oxagen-attested.

packages/dod/src/frames.ts

// packages/dod/src/frames.ts
// Three frame kinds in the run's hash chain. The chain is the only store; there is no dod table.
import { z } from "zod";
import { Dod } from "./schema";

/** Wrapper, at turn_start, before any tool frame. Body is the whole dod, content-addressed. */
export const DodLocked = z.object({
  kind: z.literal("dod.locked"),
  body: z.object({ dod: Dod, lock: z.string(), task_ref: z.string().optional() }),
});

/** Wrapper, once per stop. All results for that stop in one frame. */
export const DodChecked = z.object({
  kind: z.literal("dod.checked"),
  body: z.object({
    lock: z.string(), stop_attempt: z.number().int(),
    results: z.array(z.object({ id: z.string(), ok: z.boolean(), evidence: z.string(), error: z.literal(true).optional() })),
  }),
});

/** Oxagen, on the stop report. Server-attested. The seal signs it with the rest of the run. */
export const DodSettled = z.object({
  kind: z.literal("dod.settled"),
  body: z.object({
    lock: z.string(), verdict: z.enum(["held", "pending", "broken"]), reasons: z.array(z.string()), failed: z.array(z.string()),
    stop_attempts: z.number().int(), enforcement: z.enum(["enforced", "recorded"]),   // enforced at gateway or harness tier
  }),
});

/** Ledger mapping (packages/run-ledger EVENT_TYPE_REGISTRY): dod.locked → stage "context";
 *  dod.checked and dod.settled → stage "verification". Adding them amends the registry and its drift test. */

Outcomes

Three verdicts, seven reasons

heldEvery executable check passed and no human check is outstanding. Done.
pendingEvery executable check passed. A person still has to approve. Becomes held when the approval resolves in the Fleet panel. Reported as accepted in §12.8, never as proven.
brokenOne of seven reasons. The frame records which checks failed. The run may end broken only when its stop attempts are exhausted.

State is carried by border shape, not color. Held is never proven; proven is the witness's word and stays the witness's word.

packages/dod/src/reasons.ts

// packages/dod/src/reasons.ts
// Closed. A reason not in this list is a bug, not a new reason.
export const REASONS = {
  CHECK_FAILED:       "a check in the locked dod did not pass",
  ATTEMPTS_EXHAUSTED: "the wrapper blocked the stop as many times as the dod allows",
  LOCKED_LATE:        "the dod.locked frame does not precede the first tool frame",
  LOCK_MISMATCH:      "the dod the wrapper checked is not the dod that was locked",
  EVIDENCE_INVALID:   "a dod frame did not validate or its digests do not chain",
  HUMAN_PENDING:      "every executable check passed; a signature is outstanding",
  HARNESS_ERROR:      "the wrapper could not run a check; never treated as a pass",
} as const;

export type Reason = keyof typeof REASONS;

/** held: done. pending: done, awaiting a person. broken: not done, with reasons.
 *  None of these means proven. Proven is the witness verdict `flipped` (Mission Control §8.5). */
export type Verdict = "held" | "pending" | "broken";

The language

packages/dod/src/schema.ts

// packages/dod/src/schema.ts
// The whole dod language. Four check kinds. TOML is the human surface; this is the wire.
import { z } from "zod";

const id = z.string().regex(/^[a-z0-9][a-z0-9-]{0,39}$/);

export const RunCheck   = z.object({ id, run: z.string().min(1), timeout_s: z.number().int().positive().default(600) });
export const FileCheck  = z.object({ id, file: z.object({
  path: z.string().min(1), exists: z.boolean().optional(), contains: z.string().optional(),
  sha256: z.string().regex(/^sha256:[0-9a-f]{64}$/).optional() }) });
export const DiffCheck  = z.object({ id, diff: z.object({ allow: z.array(z.string()).default(["**"]), deny: z.array(z.string()).default([]) }) });
export const HumanCheck = z.object({ id, human: z.string().min(1) });

export const Check = z.union([RunCheck, FileCheck, DiffCheck, HumanCheck]);
export type Check = z.output<typeof Check>;

export const Dod = z.object({
  schema: z.literal("dod/v1"),
  task: z.string().min(1),
  match: z.object({ task_ref: z.string().optional(), slug: z.string().optional() }).optional(),
  stop_attempts: z.number().int().min(1).max(10).default(3),
  source: z.enum(["authored", "drafted"]).default("authored"),
  drafter: z.string().optional(),                 // model id, set by Oxagen when source = drafted
  check: z.array(Check).min(1).max(40),
}).superRefine((d, ctx) => {
  const ids = d.check.map((c) => c.id);
  if (new Set(ids).size !== ids.length) ctx.addIssue({ code: "custom", message: "check ids must be unique" });
  if (!d.check.some((c) => !("human" in c))) ctx.addIssue({ code: "custom", message: "at least one executable check is required" });
  if (d.source === "drafted" && !d.drafter) ctx.addIssue({ code: "custom", message: "a drafted dod names its drafter" });
});
export type Dod = z.output<typeof Dod>;

The decision

packages/dod/src/verdict.ts

// packages/dod/src/verdict.ts
// Pure. No clock, network, filesystem, or model. The wrapper, Oxagen, and a third party's verifier
// run this on the same frames and must produce the same bytes.
import type { Reason, Verdict } from "./reasons";
import type { Dod } from "./schema";

export interface Frame { seq: number; kind: string; body: any }
export interface Evidence {
  dod: Dod; lock: string; lockedSeq: number; firstToolSeq: number | null;
  stopAttempts: number; results: { id: string; ok: boolean; error?: true }[]; checkedLock: string | null;
  signatures: string[];           // ids of human checks resolved through the approvals panel
}
export interface Outcome { verdict: Verdict; reasons: Reason[]; failed: string[] }

/** Fold the chain into evidence. Deterministic given the frames and the signatures. */
export function evidenceFromFrames(frames: Frame[], signatures: string[]): Evidence | null {
  const locked = frames.find((f) => f.kind === "dod.locked");
  if (!locked) return null;
  const tool = frames.find((f) => f.kind === "tool_requested" || f.kind === "tool.call_completed");
  const checked = frames.filter((f) => f.kind === "dod.checked").at(-1);
  return {
    dod: locked.body.dod, lock: locked.body.lock, lockedSeq: locked.seq, firstToolSeq: tool?.seq ?? null,
    stopAttempts: checked?.body.stop_attempt ?? 0, results: checked?.body.results ?? [], checkedLock: checked?.body.lock ?? null,
    signatures,
  };
}

export function decide(e: Evidence): Outcome {
  const reasons = new Set<Reason>(); const failed: string[] = [];
  if (e.firstToolSeq !== null && e.lockedSeq > e.firstToolSeq) reasons.add("LOCKED_LATE");
  if (e.checkedLock !== null && e.checkedLock !== e.lock) reasons.add("LOCK_MISMATCH");
  if (e.stopAttempts > e.dod.stop_attempts) reasons.add("ATTEMPTS_EXHAUSTED");

  for (const c of e.dod.check) {
    if ("human" in c) continue;
    const r = e.results.find((x) => x.id === c.id);
    if (!r || r.error) { failed.push(c.id); reasons.add("HARNESS_ERROR"); continue; }
    if (!r.ok) { failed.push(c.id); reasons.add("CHECK_FAILED"); }
  }
  if (reasons.size) return { verdict: "broken", reasons: [...reasons], failed };

  const unsigned = e.dod.check.filter((c) => "human" in c).map((c) => c.id).filter((h) => !e.signatures.includes(h));
  if (unsigned.length) return { verdict: "pending", reasons: ["HUMAN_PENDING"], failed: unsigned };
  return { verdict: "held", reasons: [], failed: [] };
}

The outside dependency

An auditor, an insurer, or the customer's customer takes the run export and gets the same bytes Oxagen got. This is the one piece of the earlier spec the review asked to keep.

packages/dod/src/verify.ts

// packages/dod/src/verify.ts
// The outside dependency. A customer's auditor exports the run (Mission Control §8.3 already publishes
// the attester key ids) and recomputes the verdict with no account, no network, and no trust in Oxagen's answer.
import { decide, evidenceFromFrames, type Frame } from "./verdict";
import { digestJcs } from "@oxagen/run-evidence";

export interface RunExport { frames: Frame[]; signatures: string[]; attestation: { merkle_root: string; signature: string; key_id: string } }

export function verify(x: RunExport): { ok: boolean; expected: unknown; found: unknown } {
  const settled = x.frames.find((f) => f.kind === "dod.settled");
  const e = evidenceFromFrames(x.frames, x.signatures);
  if (!settled || !e) return { ok: false, expected: "dod.locked and dod.settled frames", found: null };
  const expected = decide(e);
  const found = { verdict: settled.body.verdict, reasons: settled.body.reasons, failed: settled.body.failed };
  return { ok: digestJcs(expected) === digestJcs(found), expected, found };
}
// `oxagen dod verify export.json` wraps this and also checks the Merkle root against the published key.

The wrapper

Two lifecycle points, reached through the hooks for Claude Code and the checkpoint gate for everything else. Frames go to oxagend; the draft and the stop report go through the gate.

packages/dod-harness/src/hooks.ts

// packages/dod-harness/src/hooks.ts
// Two lifecycle points. Claude Code reaches them through the hooks the enrollment writes
// (Mission Control §7.2); every other adapter reaches them through the checkpoint gate.
// Nothing here decides anything; decide() in @oxagen/dod does.
import { Dod, decide, evidenceFromFrames, lockDigest } from "@oxagen/dod";
import { gate } from "./gate";            // checkpoint gate: draft, stop
import { collector } from "./collector";  // oxagend: emit frames, read this run's frames
import { loadAuthored, runChecks, writeForHumans } from "./local";

/** turn_start (Claude Code: UserPromptSubmit). Lock the dod before the first tool frame. */
export async function onTurnStart(i: { run: string; prompt: string; cwd: string; task_ref?: string }) {
  if (collector.frames(i.run).some((f) => f.kind === "dod.locked")) return {};          // one lock per run
  const dod = loadAuthored(i.cwd, i.task_ref) ?? Dod.parse(await gate.draft({ run: i.run, prompt: i.prompt, task_ref: i.task_ref }));
  const lock = lockDigest(dod);
  await collector.emit(i.run, { kind: "dod.locked", body: { dod, lock, task_ref: i.task_ref } });
  writeForHumans(i.cwd, i.run, dod);                                                     // $OXAGEN_RUN_DIR/dod.toml, read-only
  return { hookSpecificOutput: { hookEventName: "UserPromptSubmit",
    additionalContext: `Your definition of done is locked (${lock.slice(0, 19)}), ${dod.check.length} checks. The run cannot end until they pass. Read it at $OXAGEN_RUN_DIR/dod.toml.` } };
}

/** stop (Claude Code: Stop). Run the checks, emit one frame, decide. Block or let the run end. */
export async function onStop(i: { run: string; cwd: string; base: string }) {
  const frames = collector.frames(i.run);
  const locked = frames.find((f) => f.kind === "dod.locked");
  if (!locked) return {};                                                                // no dod, no opinion
  const attempt = 1 + (frames.filter((f) => f.kind === "dod.checked").at(-1)?.body.stop_attempt ?? 0);
  const results = await runChecks(locked.body.dod, i.cwd, i.base);
  await collector.emit(i.run, { kind: "dod.checked", body: { lock: locked.body.lock, stop_attempt: attempt, results } });
  const o = decide(evidenceFromFrames(collector.frames(i.run), [])!);
  if (o.verdict === "broken" && !o.reasons.includes("ATTEMPTS_EXHAUSTED")) {
    return { decision: "block", reason: `dod broken: ${o.reasons.join(", ")}. Failed: ${o.failed.join(", ")}` };
  }
  await gate.stop(i.run);      // Oxagen re-decides from the chain and appends dod.settled; the seal signs it
  return {};
}

packages/dod-harness/src/checks/run.ts

// packages/dod-harness/src/checks/run.ts
// The only check that executes anything. It runs where the agent runs, never in Oxagen.
import { spawn } from "node:child_process";
import { createHash } from "node:crypto";

export interface CheckResult { id: string; ok: boolean; evidence: `sha256:${string}`; error?: true }

export function runCheck(id: string, cmd: string, cwd: string, timeoutS: number): Promise<CheckResult> {
  return new Promise((resolve) => {
    const hash = createHash("sha256");
    const child = spawn(cmd, { cwd, shell: true, env: scrubbed(process.env), stdio: ["ignore", "pipe", "pipe"] });
    const timer = setTimeout(() => child.kill("SIGKILL"), timeoutS * 1000);
    const done = (ok: boolean, error?: true) => { clearTimeout(timer); resolve({ id, ok, evidence: `sha256:${hash.digest("hex")}`, ...(error && { error }) }); };
    child.stdout.on("data", (d) => hash.update(d));
    child.stderr.on("data", (d) => hash.update(d));
    child.on("error", () => done(false, true));
    child.on("close", (code, signal) => (signal ? done(false, true) : done(code === 0)));
  });
}

/** Keep the toolchain, drop credentials. A check that needs a secret is not a dod check. */
function scrubbed(env: NodeJS.ProcessEnv): NodeJS.ProcessEnv {
  const keep = ["PATH", "HOME", "SHELL", "LANG", "TERM", "NODE_OPTIONS", "PNPM_HOME", "CI"];
  return Object.fromEntries(keep.filter((k) => env[k]).map((k) => [k, env[k]]));
}

packages/dod-harness/src/checks/diff.ts

// packages/dod-harness/src/checks/diff.ts
// Scope is a diff manifest against the run's base commit (Mission Control §8.1), not a snapshot.
import { execFileSync } from "node:child_process";
import { digestJcs } from "@oxagen/run-evidence";
import { matchesAny } from "@oxagen/glob";
import type { CheckResult } from "./run";

export function diffCheck(id: string, cwd: string, base: string, allow: string[], deny: string[]): CheckResult {
  const changed = execFileSync("git", ["diff", "--name-only", `${base}...HEAD`], { cwd, encoding: "utf8" });
  const untracked = execFileSync("git", ["ls-files", "--others", "--exclude-standard"], { cwd, encoding: "utf8" });
  const files = [...changed.split("\n"), ...untracked.split("\n")].filter(Boolean).sort();
  const outside = files.filter((f) => !matchesAny(f, allow) || matchesAny(f, deny));
  return { id, ok: outside.length === 0, evidence: digestJcs({ base, files, outside }) };
}

// packages/handlers/src/dod.settle.ts
// Oxagen executes nothing (ADR-043). It reads the chain, runs the same decide() the wrapper ran,
// appends one server-attested frame, and the kernel records the governed action around it (ADR-052).
import { decide, evidenceFromFrames } from "@oxagen/dod";
import { appendFrame, readFrames, enforcementTier } from "@oxagen/run-ledger";
import { resolvedApprovals } from "@oxagen/handlers/agent.approval";     // human checks are approvals; nothing new

export async function settleDod(input: { run: string }, ctx: CapabilityContext) {
  const frames = await readFrames(ctx, input.run);
  const e = evidenceFromFrames(frames, await resolvedApprovals(ctx, input.run, "dod"));
  if (!e) throw new DodNotLockedError(input.run);
  const o = decide(e);
  const tier = await enforcementTier(ctx, input.run);                       // gateway | harness | observe
  const settled = await appendFrame(ctx, input.run, {
    kind: "dod.settled",
    body: { lock: e.lock, ...o, stop_attempts: e.stopAttempts, enforcement: tier === "observe" ? "recorded" : "enforced" },
  });
  return { ...o, settledSeq: settled.seq, enforcement: settled.body.enforcement };
}

Trust boundary

What a held dod warrants, and what it does not

A held dod warrants

The run's own frames decide to held under the dod locked before its first tool call. The dod.settled frame was appended by Oxagen and is covered by the seal's Merkle root and the run attestation. Anyone with the frames and decide() can recompute the verdict offline.

A held dod does not warrant

That the dod was the right dod. That the agent's host was not tampered with. That the change did what the task asked. The first belongs to whoever authored it. The second is the same trust §8.3 already names for client-attested frames: Oxagen attests receipt and chain integrity, not the content. The third is the witness's job, and only the witness's word is proven.

Enforcement is reported as it is. At gateway or harness tier the stop was actually blocked and the frame says enforced. At observe tier the checks were recorded and the frame says recorded. The run page shows the word from the frame and nothing stronger.

THE SYSTEM IN ONE PARAGRAPH
At turn_start the wrapper (oxagen-hook for Claude Code, the checkpoint gate for every other adapter) loads an authored dod from .oxagen/dod/*.toml by task reference or slug, or asks Oxagen to draft one from the prompt. It locks it by lockDigest, emits a dod.locked frame whose body is the whole dod, and tells the agent where to read it. At stop it runs every executable check on the agent's host, emits one dod.checked frame with every result, folds the run's own frames into evidence, and calls decide(). If broken and stop attempts remain, it blocks the stop and hands the agent the failing ids. Otherwise it reports the stop through the checkpoint gate; Oxagen reads the chain, runs the same decide(), appends a server-attested dod.settled frame, and records one governed action. The seal signs it with the rest of the run. Verdicts: held, pending, broken. A held dod means done. It never means proven; proven is the witness verdict flipped.

HARD CONSTRAINTS
- decide() and evidenceFromFrames() are pure. Same frames in, same bytes out, on the wrapper and in Oxagen.
- Four check kinds only: run, file, diff, human. Anything else composes from run. Budgets are Mission Control budgets (§12.5); tool policy is the toolbelt's (§6.4). The dod duplicates neither.
- Seven reasons, closed, in packages/dod/src/reasons.ts. A timeout, crash, or missing result is HARNESS_ERROR and rejects.
- The dod.locked frame must precede the first tool frame in the chain, or the verdict is broken with LOCKED_LATE.
- The chain is the only store. No dod table. The locked dod lives in the dod.locked frame body; the outcome lives in the dod.settled frame; the seal signs both. LOCK_MISMATCH is a chain check, not a database lookup.
- Oxagen executes nothing. apps/api never imports @oxagen/dod-harness. The harness links only into oxagen-hook and apps/cli.
- The dod is fully visible to the agent. It has no hidden checks. Hidden checks are witnesses and live in the witness runner. The drafting prompt says so.
- Enforcement is reported as it is: dod.settled.enforcement is "enforced" at gateway or harness tier and "recorded" at observe tier. The UI never shows a stronger word.
- stop_attempts is honored. When exhausted, settle as broken and let the run end. Never loop.
- The drafting model is recorded on the dod (drafter) and is never the model running the task.
- Human checks are approvals. Resolving one uses the existing approvals panel and resolve_approval. No dod.sign capability, no new table.
- packages/dod/src/verify.ts recomputes a verdict from a run export with no network and no account, and `oxagen dod verify` wraps it. This is the third-party entry point; keep it dependency-free.
- Frame kinds are added to EVENT_TYPE_REGISTRY with their stage (dod.locked → context; dod.checked and dod.settled → verification) and the drift test and CHECK constraint are updated in the same PR.
- Human-readable files follow the house prose rules: sentence case headings, no em dashes, short actor-first sentences, Oxagen capitalized in prose, run not session, run not trace, resumed not attempt.
