The claim

One sentence, and the category it names

Oxagen is the control plane for agent work. It locks a definition of done into every run before the agent's first tool call, blocks the run from ending until that definition holds, and settles the result into a signed record anyone can verify offline.

Not observability, governance, evals, or guardrails. Each of those is owned by someone, and each one means watch and report. Oxagen acts: it blocks a run from ending. Name the category by what it does and let the dod carry the difference.

Pre-committed

The dod is locked before the agent moves. Its position in the chain proves it. Everything else in the category scores afterward, with a model that shares the worker's blind spots.

Two halves

The dod is visible to the agent, so drift is caught where it happens. The witness is hidden, so gaming is caught where it hides. Nobody else ships both.

Outside dependency

oxagen dod verify runs with no account and no network. The day an auditor runs it, Oxagen is infrastructure.

Proof points

Stated so they survive a rebuttal

  1. Pre-committed, not post-hoc. The lock's position in the chain is the proof. Evals score afterward.
  2. No model in the verdict. decide() is a pure function of the run's frames. Put the source on the website.
  3. Two halves, on purpose. Visible dod for drift, hidden witness for gaming.
  4. Third parties depend on the record. Verify needs no account and no network.
  5. The meter follows the proof. Pay for proven runs. Runs and governed actions are secondary meters.
  6. Sixty seconds. Two hooks in Claude Code. The first screen shows your own numbers.

Never name a competitor. Describe the category behavior: tools that record, scores written after the fact, a second model grading the first. The reader supplies the names.

Words

Use these. Avoid those.

Use

Nouns. run, turn, step, frame, operator, agent, workspace, governed action, dod, check, lock, verdict, seal, export, witness.

Verbs. lock, block, hold, break, settle, verify, wrap, record, seal, decide, read, show, cost.

Verdicts. held, pending, broken. Done for a held dod. Proven only for a flipped witness.

Avoid

Empty. seamless, robust, powerful, revolutionary, comprehensive, end-to-end, intelligent, magic.

Emotional. excited, thrilled, finally, imagine, liability, unchecked, protect.

Owned categories. observability, governance as a noun, evals, guardrails, trust layer.

Wrong vocabulary. session, trace, attempt, execution, invocation, stamp, certificate, AI-powered, agentic.

Overclaims. proven for the dod, verified for a model, guaranteed, always, 100%.

Product page, the dod section

Define done before the agent starts

A dod is a short file with four kinds of check: a command that must exit clean, a file that must contain a line, a diff that must stay inside a set of paths, and a judgment a named person signs after the run. You write one by hand for a task that repeats, or Oxagen drafts one from your prompt. Either way it is locked before the first tool call, and the agent can read it and cannot change it.

The run cannot end until it holds

When the agent tries to stop, the wrapper runs every check on the agent's own machine and records the results as a frame in the run. Broken, and the agent gets the failing ids and keeps working. Held, and Oxagen settles the result. Broken three times, and the run ends broken, on the record, with the reasons.

Prove it to someone who doesn't trust you

The verdict is a pure function of the run's frames. There is no model in it. Export the run and hand it to your auditor; oxagen dod verify recomputes the verdict with no account and no network and tells them whether it matches.

Docs introduction

Oxagen adds two hooks to Claude Code. The first runs when you submit a prompt: it loads a definition of done for the task, or drafts one, and locks it into the run. The second runs when the agent tries to stop: it runs the checks and blocks the stop if any fail. Everything else happens in Oxagen and you can read it on the run page.

To install, open the Agents page and choose Wrap Claude Code. The installer writes the hooks and enrolls this machine. The page turns to connected when the first frame arrives.

Launch post, opening

Today a coding agent tells you it is finished, and you read the PR to find out whether it was right. That order is backwards, and it is the reason agent output still needs a person to read every line.

Oxagen reverses it. Before an agent makes its first tool call, the run has a definition of done: a locked file with the commands that must pass, the files that must change, the paths that must not, and the judgment a person will sign. The agent can read it. It cannot change it. And the run cannot end until the checks hold.

We built the dod on Mission Control's run record, so every check result is a frame in the same chain as every tool call and every model call, and the seal signs all of it. Export the run and anyone can recompute the verdict with fifteen lines of code and no account. We think that last part matters more than any of the rest, because it is the first thing in this category an outside party can depend on.
