Summary

Summary

  • Claude Code and Codex have code on main for every tier, though no production run has reached contained. stella reaches gateway, and Cursor reaches harness.
  • Claude Code's hook contract is now the common one. Codex, Copilot, Cursor, Gemini CLI, Goose, and Devin use close copies. Codex and Cursor already run Oxagen's hook, so one settings writer per harness could bring in Gemini CLI, Goose, Copilot CLI, and Devin.
  • Every open-source product accepts a model base URL, so each can reach gateway for model traffic. Cursor, Devin Desktop, and the Copilot coding agent keep model calls on their own servers.
  • No framework has an Oxagen adapter. Each framework exposes a tool hook, a base URL, and a telemetry export, so one adapter per language covers most of them.
  • Five products read MCP tools but not MCP resources. Oxagen's steering reaches agents as MCP tools (steering_search, steering_read), so the gap does not block steering over MCP.
  • Copilot and Goose hooks let a call through when the hook fails, unless configured otherwise. Among the first-class harnesses, only Cursor has a setting (failClosed) that catches a crashed hook.

Decided

  • Oxagen supports each first-class harness (Claude Code, Cursor, Codex, and stella) as fully as that harness allows. (Mac, 2026-09-26)
  • Oxagen supports the most popular frameworks, starting with LangChain, the Claude Agent SDK, the OpenAI Agents SDK, and the Vercel AI SDK. (Mac, 2026-09-26)
  • Cursor gets steering through Oxagen's MCP server, plus one rule in Cursor's dashboard. (Mac, 2026-09-26)

Proposed

  • Every "Tier possible" value, the framework adapters, the settings writers for other harnesses, and the build order.
Tiers

Tier ladder

A run's tier says how much of it passed through Oxagen. The control plane computes it from the run's record, and a product's tier here is the highest its runs could earn.

TierWhat passes through OxagenWhat the product needs
observeEvents the product exportsA telemetry export or a transcript
harnessLifecycle events. Hooks deliver steering and can refuse a callA tool-call hook or middleware that can deny, installed by Oxagen
gatewayModel or MCP traffic, which the gateway meters and enforces budgets onA model base URL, or MCP calls through Oxagen's gateway
containedEvery network request from an OS sandbox whose only exit is the gatewayHooks, a base URL, a launcher profile, and no network need beyond the gateway. Today's profile is oxagen-linux-docker-v1

Tiers stack for a wrapped harness. A product with a base URL and no hooks, such as Aider, reaches gateway with no harness rung under it, as Claude Desktop does through its Oxagen MCP calls. A harness tier fails open against the person at the keyboard, who can remove the hook.

For a framework, an Oxagen adapter's middleware plays the hook's part. It runs in your app's code, so it fails open against whoever owns that code, the same as a hook. Proposed

Build

Build order

Ordered by how much each step adds for the products Mac named. Proposed

  1. First-class gaps.

    Build the MCP aggregator (oxagen #3299) so MCP traffic from Claude Code, Codex, and stella reaches the gateway. Route Cursor's MCP calls through the cloud gateway. Give stella a launcher profile and a spend export.

  2. Claude Agent SDK.

    Reuse Claude Code's hooks and base URL. It is the smallest step, since the SDK runs Claude Code.

  3. Framework adapters.

    One TypeScript package (Vercel AI SDK, OpenAI Agents SDK, LangChain.js, Mastra) and one Python package (LangChain and LangGraph, OpenAI Agents SDK, Pydantic AI, CrewAI, Google ADK). Each does four things: a tool-call middleware that asks Oxagen, the model base URL, a telemetry export, and steering fetched at run start.

  4. Hook-contract harnesses.

    Add a settings writer for Gemini CLI, Goose, Copilot CLI, and Devin, and an OpenCode plugin. Each reuses tacho-hook.
