# Mockup versions

Version 4 is the frozen reference in `v4/`. Its `SNAPSHOT.json` records the source commit and SHA-256 of each copied file.

Version 5 is developed in this directory. It must match the rebaselined Oxagen product, including its existing capabilities and the Runtimes page. The product and this mockup use Agents for the agent page and Runtimes for the computers agents run on.

Version 5 does not introduce schemas or permission inheritance to fill gaps in the reference. Existing product features absent from version 4 remain explicit, under the placements approved by Mac.

The witness, proof of value, and product definition-of-done features remain paused.

The machine-first onboarding flow is a v5 proposal awaiting Mac’s approval. Its preview controls simulate receipts and do not change the product.
