    Design reference

    Typography

    The app surface uses three typefaces, and each has one job. Space Grotesk sets the page title. Geist sets everything a person reads. Monaspace Neon sets code, ids, and anything a person copies or compares character by character.

    Source mockups/src/engine.css lines 16 to 70 Fonts tools/lib/house-fonts.mjs Rule set 2026-09-25

    The display face rule

    Space Grotesk sets the page h1 in the app surface and nothing else.

    1. Space Grotesk sets the page h1 only.

      One per page: the page title in .phead, the record title in .crec-h, and the onboarding step title in .ob-h. It is never set below 20px, including on a phone.

    2. Geist sets every other heading.

      Section titles (h2), dialog titles, drill headers, card and panel titles (h3), group labels (h4), and table headers. It also sets body text, labels, buttons, tabs, badges, inputs, tooltips, and navigation.

    3. Monaspace Neon sets code and identifiers.

      Code blocks, inline code, the source editor, diffs, the transcript, commands, file paths, ids, digests, frame kinds, verdict values, and stored keys.

    4. No fourth typeface.

      The one exception is an operator's own avatar: the avatar editor offers Serif, which sets that monogram in Georgia.

    Space Grotesk has wide, geometric letters. At panel-title sizes (13 to 15px) the counters close up and the words blur, which is what made the table panel titles hard to read. Geist holds its shape down to 10px.

    Headings

    A page has one h1, and every heading below it names a thing.

    LevelUsed forFaceCount per page
    h1The page, record, or onboarding step titleSpace GroteskExactly one
    h2A section, a dialog, a drill header, an empty or error stateGeistAny
    h3A panel, a card, a drawer sectionGeistAny
    h4A group inside a panel or a formGeistAny
    • Headings are sentence case and plain nouns: "Spend by area", "Repository", "Toolbelt". Prose has the full rule.
    • Subtext under a heading is one sentence or nothing, in --muted at 12.5 to 13px.
    • A heading that holds an id is set in mono with class="mono", and its size drops a step (18 to 20px for an h1).
    • Heading levels follow the document outline. Pick the level for structure, then let the selector set the size.

    Body and interface text

    Geist at 13 to 14px carries almost every word on the surface.

    • Body is 14px with a 1.55 line height. Paragraphs stop at 70 to 78 characters (max-width:70ch on page subtext, 78ch on record statements).
    • Secondary text (subtext, stat sublines, notes) is 11.5 to 13px in --muted.
    • Controls: buttons and tabs are 13px at 500. A small button is 12px. A gold primary button is 600.
    • Inputs are 13px, and 16px in the phone shell so iOS does not zoom on focus. Touch targets there are 44px tall.
    • The floor is 10px, used only for mono counts and timestamps. Nothing a person must read to act is below 11px.

    Capital labels

    Five roles are set in capitals, and CSS does the capitalizing.

    • Write the source in sentence case ("Agent", "Tokens"). text-transform:uppercase sets the capitals, so a screen reader reads a word and a copy keeps its case.
    • An identifier inside a capital label keeps its case: wrap it in .id. wo_01K6T9QX stays lowercase.
    • Capitals get positive tracking. Everything else is set at 0 or tighter.

    Monospace

    Monaspace Neon sets the code editor and every source display.

    Mockup

    Confirmed

    --mono is "Monaspace Neon" (engine.css:16). The source editor (.ed-scroll, line 953), pre (298), code (302), diffs (.diff, 974), and the transcript (.tx-*) all read it. The build inlines the font file, so the mockup sets it offline.

    Product app

    Confirmed

    packages/ui/src/styles/house-fonts.css:14 loads Monaspace Neon, globals.css:987 maps it to --font-mono, and apps/app/src/ui/code-editor.tsx sets the textarea and its highlighted twin in it.

    What is set in mono

    • Code, commands, terminal output, logs, and diffs.
    • Ids and references: run_01K5RS7M2E8FJ3QW, wo_01K6T9QX, a4c91e2, a-intel/platform#590.
    • File paths, branch names, digests, hashes, and stored keys shown as keys.
    • Frame kinds (tool.call), verdict values (held), and tier names (gateway).
    • Counts in tabs and navigation, and timestamps in lists.

    What stays in Geist

    • Money and stat values. They use Geist with font-variant-numeric:tabular-nums, so figures line up without a code face.
    • A stored key shown to a person. The page shows its label ("Observed by gateway") and keeps the key (gateway_observed) in a tooltip.

    Features

    Monaspace's texture healing rides the calt feature, and its code ligatures ride liga. Both are on by default in every browser, and nothing in engine.css turns them off. Never set font-variant-ligatures:none on mono text.

    Sizes

    .mono is 0.92em and code is 0.9em, so inline mono matches the x-height of the Geist around it. Blocks set their own size: pre 12px, the editor 12.5px on a 20px line, diffs 11.5px.

    Figures

    Numbers that are compared line up.

    • Stat values, table columns of figures, meters, and pagers use tabular figures (.num or font-variant-numeric:tabular-nums).
    • Money goes through usd(): a dollar sign, thousands separators, two decimals, and a true minus sign (−). Counts go through plural(). Prose has the wording rules.

    Wordmarks

    The marks are artwork, and the brand sets them in Space Grotesk.

    • The oxagen lockup and the stella wordmark are SVG paths (LOGO, stellaWordmark()). They are drawn, so the type rule does not apply to them.
    • Three places set a name as text in the wordmark's face: .stl-ask ("Ask stella*" on the assistant launcher, 13.5px), .stl-name (the name in an assistant message, 12.5px), and .ox-name (oxagen on the launcher's second line, 11px). Mac chose this on 2026-09-21, and tools/check-assistant.mjs asserts it. It is the one open exception below 20px. See Findings.

    Findings

    What the 2026-09-25 font audit changed and what it left open.

    fixedSpace Grotesk on every h2 and h3

    engine.css:61 set h1,h2,h3 in the display face, so every panel title (13.5px), card title (15px), section title (18px), and dialog title (16px) rendered in Space Grotesk. The rule is now h1 only, in rev1 and in future_state_mockups/. approved-profile-flow/ set its card h2 in the display face locally. That is Geist now.

    fixedDisplay face below 20px

    The record title dropped to 18px on a phone, and a record title over 90 characters dropped to 19px. Both stop at 20px now.

    openText-set wordmarks

    .stl-ask, .stl-name, and .ox-name set names in Space Grotesk at 11 to 13.5px. Moving them to Geist is a one-line change in engine.css plus the four assertions in tools/check-assistant.mjs. It waits on Mac, since the 2026-09-21 decision put them there.

    openThe brand kit and the product app say h1 to h3

    The oxagen-branding checklist and oxagen/packages/ui/src/styles/globals.css:1022 still set h1 to h3 in Space Grotesk. The fix belongs in the brand kit first, then the vendored copies and the app.

    noteThe snapshot keeps the old rule

    mockups/rev-2/ is a snapshot that is never edited. It keeps h1,h2,h3 in Space Grotesk and is not the design of rev1.

    note9.5px text

    Three rules set 9.5px: a finding's avatar initials (.fnd .who .av), the workspace switcher badge, and the debug chrome label. All three are below the 10px floor.

## Inputs

1. mockups/typography.html in the roadmap repo. Read it in full. Its rules, its type scale table, and its monospace section are the spec.
2. mockups/src/engine.css: lines 1 to 70 (the font tokens and the heading rules), and every rule that sets font-family, font-size, font-weight, letter-spacing, or text-transform.
3. The build's global stylesheet, its font loading (next/font, @font-face, or a link tag), and its token or Tailwind config.
4. Routes to sample, desktop at 1440 by 1000: Work, Agents, one agent's Overview, one run, Spend, Steering, one dialog, and the approvals drawer. Then the phone shell at 390 by 844 with a touch pointer.

## Procedure

Record PASS, FAIL, or N/A for every check. Cite evidence for each: a file and line in the build, or a DOM selector with its computed style (getComputedStyle: fontFamily, fontSize, fontWeight, lineHeight, letterSpacing, textTransform).

1. Faces loaded. Exactly three families load: Space Grotesk, Geist, and Monaspace Neon. Report each one's source and loaded weights. Any other family in first position of a computed fontFamily is a FAIL, except Georgia on an avatar the operator set to Serif.
2. Space Grotesk scope. Collect every element whose computed fontFamily starts with Space Grotesk. Each must be the page h1 at 20px or larger, or a wordmark. Every other hit is a FAIL: list its selector, text, size, and route. Panel titles, card titles, section and dialog titles, drill headers, table headers, stat values, tabs, and buttons in Space Grotesk are the known failure.
3. One h1. Every routed page has exactly one h1, and it is the page, record, or onboarding step title.
4. Geist scope. h2, h3, h4, body text, labels, buttons, tabs, badges, inputs, table headers and cells, tooltips, and navigation compute to Geist.
5. Monaspace scope. pre, code, kbd, the source editor, diffs, the transcript, ids (run_, wo_, tsk_), commit hashes, digests, file paths, commands, frame kinds, verdict values, and stored keys shown as keys compute to Monaspace Neon. A fallback family in first position (ui-monospace, SF Mono, Menlo, Consolas, JetBrains Mono, Geist Mono, Courier) is a FAIL.
6. Code editor. Open a steering source or an agent definition in the editor. The textarea and the highlighted layer beneath it both compute to Monaspace Neon with the same font size, line height, and padding. Type a long line and confirm the caret stays on its glyph. A mismatch is a FAIL.
7. Ligatures. Nothing sets font-variant-ligatures: none, or a font-feature-settings that drops calt or liga, on monospace text.
8. Scale. For every row of the type scale table, find the build's equivalent element and compare size, weight, line height, tracking, case, and color token. A size off by more than 0.5px, or any weight, case, or face difference, is a FAIL. Quote both values.
9. Floor. No text renders below 10px. Nothing a person must read to act renders below 11px. Inputs, selects, and textareas compute to 16px in the phone shell.
10. Capitals. Headings, buttons, labels, and table headers are sentence case in the source. Capitals come only from text-transform, and only on eyebrows, table headers, stat labels, kind badges, and group labels. An identifier inside a capital label keeps its case.
11. Figures. Stat values and figure columns use tabular figures, and a column of amounts lines up.
12. Line length. Body paragraphs stop at about 78 characters.
13. Weights. Only 400, 500, 600, and 700 are in use. List any other weight with its selector.
14. Phone shell. The page h1 is 20px, nothing scrolls sideways, and no heading wraps to more than three lines.
15. Themes. Repeat checks 2, 4, and 5 in the light theme. Typography does not change with the theme.
